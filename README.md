# Jander Cup 2026
Live Supabase-connected multiplayer foundation.

## Run locally
1. Install Node.js 20+
2. In this folder: `npm install`
3. Run: `npm run dev`
4. Open http://localhost:3000

## Deploy
Upload/import this project to Vercel. Add:
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY

## Working now
Anonymous auth, golfer selection, shared score entry, realtime score updates, realtime chat, live gross totals.
